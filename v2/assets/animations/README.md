# Approved walk cycles

The selected direction is **gentler motion for Spiro, livelier motion for all six animals**.

- `guide-walk.png`: Spiro's gentler B photographic cutout cycle, articulated
  around shoulders, hips, and knees, with a small body bob. This is not a new side-view drawing.
- Species sheets: continuous deformations of each original crayon drawing,
  emphasizing legs, trunks, tails, flippers, or slithering as appropriate.

Each transparent PNG holds twelve frames in one horizontal row, played at
12 fps. `v2/walk-animation.js` defines their frame dimensions and padding.
Padding provides space for moving limbs but never changes collision boxes.
The original still images remain the idle, carried, reduced-motion, and missing
sheet fallback artwork. The victory flip also uses the original player cutout.

These are the approved outputs only. Exploratory pages, alternate cycles,
illustrated character interpretations, and prototype generators were removed.
